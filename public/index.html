A natural voice agent greets the caller, understands them in real time, and calls real tools: confirms stock and today's market prices, places wholesale orders, quotes bulk pricing, tracks deliveries, and escorts angry callers to the produce manager — confirmation numbers read aloud.

Deep on the AssemblyAI stack — not a chatbot wrapper

The sponsor's entire voice platform is the product, not an afterthought.

🎙️

Voice Agent API

One WebSocket = real-time speech-to-speech with turn detection, barge-in, keyterms biasing, and server-side HTTP tools that our app answers with real orders and quotes — no STT/LLM/TTS stack to stitch.

🧠

LLM Gateway + Speech Understanding

Every finished conversation is analyzed through AssemblyAI's LLM Gateway: structured summary, sentiment, intent, action items, and a "needs human" flag — returned as strict JSON.

🗂️

Session History & recordings

The dashboard links each call to its AssemblyAI session record — recording, conversation timeline, and metadata artifacts — for compliance, coaching, and QA.

🔐

Stored agents + one-time tokens

Each business gets a reusable agent registered via the Agents REST API. Browsers connect with short-lived temporary tokens, so the API key never leaves the server.
